# Safa Makkah Kuwait — demo storefront

This is a static demo website prepared for GitHub Pages. The storefront is in Arabic and right-to-left. No server or build step is required.

## Publish with GitHub Pages

1. Create a repository on GitHub. Make it public if you want the published page to open for anyone with its link. The source files will then also be visible.
2. Upload the contents of this folder to the repository root, including `index.html`, the `assets` folder, and `.nojekyll`.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and `/ (root)`, and save.
4. GitHub will show the public Pages URL in that same section after it finishes publishing.

## Demo limitations

Prices are samples. Cart and checkout work only in the browser; orders and form entries are not sent or saved, and no payment gateway is connected. The product photos and logo are the original Safa Water assets. Confirm brand and image usage rights with the Kuwait distributor before commercial launch.
